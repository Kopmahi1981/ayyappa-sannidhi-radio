# Ayyappa Sannidhi Radio (అయ్యప్ప సన్నిధి రేడియో)

An immersive digital shrine and sacred internet radio dedicated to Lord Ayyappa (Manikanta), playing timeless devotional songs across Telugu, Tamil, and Malayalam, with client-side audio upload and IndexedDB persistence.

## Features
- **100dvh Single Page Sanctuary**: Pure full-screen immersive layout with zero vertical page scroll.
- **Dual Playback Engine**: Seamless switching between official YouTube IFrame API and HTML5 `<audio>` element.
- **IndexedDB Upload Engine**: Drag-and-drop custom MP3/WAV/AAC/M4A devotional tracks stored persistently in the browser.
- **Temple Bell Synthesizer**: Authentic Web Audio API bronze chime harmonics on interactive Diya tap.
- **Realtime Panchangam Ticker**: Live astronomical calculations (Tithi, Nakshatra, Muhurtham, Rahu Kaalam).
- **18 Sacred Pilgrimage Chants**: Full Sharanu Ghosha soundboard in Telugu, Tamil, Malayalam, and English.
- **Keyboard Navigation**: Space to play/pause, M to mute, Esc to dismiss modal, Shift+Arrows to skip.

## Getting Started
```bash
npm run dev
```
Visit `http://localhost:3000`
